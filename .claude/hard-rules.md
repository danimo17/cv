# Hard rules (vinculants, es llegeixen cada torn)

Cada regla té un fitxer amb el detall a `.claude/rules/` i diu **què la fa complir**. Trencar-ne una és un bug,
no una preferència. Si una regla i una directiva de l'usuari xoquen: pregunta (regla 11).

| #   | Regla                                                                                                                                                                                                                                                             | Ho fa complir                                                                                        |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| 01  | Cap secret al repo, al xat ni als logs. Només `.env` local (ignorat) i secrets de GitHub/Cloudflare. Clau exposada = regenerar.                                                                                                                                   | `.gitignore`, `tests/arch/secrets.spec.ts`, gitleaks a CI                                            |
| 02  | Cap codi ni recurs intern de cap empresa (PDPAOLA inclosa). Només informació pública.                                                                                                                                                                             | Revisió humana al contracte i a la review                                                            |
| 03  | Giphy només es crida des de `server/api/giphy/*`; el client només via `app/services/giphy/GiphyService.ts` → `useGiphyStore` (decisió 029).                                                                                                                       | `tests/arch/giphy-boundary.spec.ts`                                                                  |
| 04  | Cap dada personal sensible (telèfon, adreça postal) ni a la web ni als PDFs (capa de text inclosa).                                                                                                                                                               | `tests/arch/no-pii.spec.ts` + review                                                                 |
| 05  | Cap string d'usuari hardcoded als templates; tota clau existeix als 3 locales.                                                                                                                                                                                    | `vue/no-bare-strings-in-template`, `tests/unit/i18n-parity.spec.ts`                                  |
| 06  | La IA treballa sempre en una branca `feat/<slug>`; mai commit a `main`. Mai push sense permís explícit de l'usuari en aquell moment; amb permís, pot fer `push` d'una branca `feat/*` (mai de `main`). El merge és sempre de l'usuari (decisió 031).              | Hook global git-safety (bloqueja force-push i push a `main`/`master`), branch protection a GitHub    |
| 07  | Component, store, composable, token o clau nova o canviada → catàleg de `.claude/docs/catalog/` actualitzat al mateix commit.                                                                                                                                     | `tests/arch/docs-sync.spec.ts`                                                                       |
| 08  | Cada component té el seu CSS a `app/assets/css/components/<kebab>.css`; al template només classes semàntiques pròpies; la tipografia només via `CustomText`; elements natius de text/form/enllaç/imatge només dins dels primitius `Custom*` (decisions 026, 038). | `tests/arch/css-per-component.spec.ts`, `vue/no-restricted-class`, `vue/no-restricted-html-elements` |
| 09  | Cap commit sense `pnpm gate` en verd; cap push sense `pnpm gate:push`; cap merge a `main` sense CI + seguretat en verd. Mai `--no-verify`.                                                                                                                        | `.githooks/*`, CI, branch protection, hook `require-contract`                                        |
| 10  | Cap codi sense story + contracte amb criteris Given/When/Then a `.claude/tasks/<slug>/`.                                                                                                                                                                          | Hook `require-contract` (bloqueja `git commit`)                                                      |
| 11  | Directiva clara que no es pot complir → pregunta directa amb opcions (grill-me), mai substituir en silenci. Tota decisió va a `.claude/docs/decisions/`.                                                                                                          | Revisió humana; `.claude/docs/decisions/` és la memòria                                              |
| 12  | El fil principal orquestra: contractes, decisions, síntesi i gates. Investigació i desenvolupament es deleguen a subagents.                                                                                                                                       | Revisió humana; `workflow.md`                                                                        |
