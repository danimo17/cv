# Hard rules (binding, read every turn)

Each rule has a file with the details in `.claude/rules/` and states **what enforces it**. Breaking one is a bug,
not a preference. If a rule and a user directive clash: ask (rule 11).

| #   | Rule                                                                                                                                                                                                                                                                                                                                                                                                         | Enforced by                                                                                                                                                                                  |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 01  | No secrets in the repo, the chat, or the logs. Only local `.env` (ignored) and GitHub/Cloudflare secrets. Exposed key = regenerate.                                                                                                                                                                                                                                                                          | `.gitignore`, `tests/arch/secrets.spec.ts`, gitleaks in CI                                                                                                                                   |
| 02  | No code or internal resources from any company (PDPAOLA included). Only public information.                                                                                                                                                                                                                                                                                                                  | Human review in the contract and in the review                                                                                                                                               |
| 03  | Giphy is only called from `server/api/giphy/*`; the client only via `app/services/giphy/GiphyService.ts` → `useGiphyStore` (decision 029).                                                                                                                                                                                                                                                                   | `tests/arch/giphy-boundary.spec.ts`                                                                                                                                                          |
| 04  | No sensitive personal data (phone, postal address) either on the website or in the PDFs (text layer included).                                                                                                                                                                                                                                                                                               | `tests/arch/no-pii.spec.ts` + review                                                                                                                                                         |
| 05  | No hardcoded user-facing string in templates; every key exists in all 3 locales.                                                                                                                                                                                                                                                                                                                             | `vue/no-bare-strings-in-template`, `tests/unit/i18n-parity.spec.ts`                                                                                                                          |
| 06  | The AI always works on a `feat/<slug>` branch; never commits to `main`. Never pushes without the user's explicit permission at that moment; with permission, it can `push` a `feat/*` branch (never `main`). Merging is always done by the user (decision 031).                                                                                                                                              | Global git-safety hook (blocks force-push and push to `main`/`master`), branch protection on GitHub                                                                                          |
| 07  | New or changed component, store, composable, token or key → `.claude/docs/catalog/` catalog updated in the same commit.                                                                                                                                                                                                                                                                                      | `tests/arch/docs-sync.spec.ts`                                                                                                                                                               |
| 08  | Each component has its CSS in `app/assets/css/components/<kebab>.css`; only its own semantic classes in the template; typography only via `CustomText`; native text/form/link/image elements only inside the `Custom*` primitives (decisions 026, 038).                                                                                                                                                      | `tests/arch/css-per-component.spec.ts`, `vue/no-restricted-class`, `vue/no-restricted-html-elements`                                                                                         |
| 09  | No commit without `pnpm gate` green; no push without `pnpm gate:push`; no merge to `main` without CI + security green. Never `--no-verify`.                                                                                                                                                                                                                                                                  | `.githooks/*`, CI, branch protection, `require-contract` hook                                                                                                                                |
| 10  | No code without a story + contract with Given/When/Then criteria in `.claude/tasks/<slug>/`. Closing a task requires a fully-checked archive (`.claude/templates/close-checklist.md`) in the same commit that deletes the task folder — `ACTIVE` can then stay empty until the next task starts.                                                                                                             | `require-contract` hook (blocks `git commit`; task-close-gate, decision 051)                                                                                                                 |
| 11  | A clear directive that can't be fulfilled → ask a direct question with options (grill-me), never silently substitute. Every decision goes to `.claude/docs/decisions/`.                                                                                                                                                                                                                                      | Human review; `.claude/docs/decisions/` is the memory; `require-contract` hook blocks a commit that touches `nuxt.config.ts`/`eslint.config.mjs` without a decision file staged alongside it |
| 12  | The main thread orchestrates: contracts, decisions, synthesis and gates. Research and development are delegated to subagents.                                                                                                                                                                                                                                                                                | Human review; `workflow.md`                                                                                                                                                                  |
| 13  | **Everything in English**: code, comments, file names, `.claude/` docs (rules, decisions, standards, catalog, contracts, handoffs), `CLAUDE.md`, commits and PRs (decision 040). Only exception: the natural content of `i18n/locales/*.json` (ca/es/en). Migrated 2026-09-18.                                                                                                                               | Human review; consider `tests/arch/language.spec.ts`                                                                                                                                         |
| 14  | **No comments in code.** Every file outside `.claude/` (app/, server/, shared/, root config) is comment-free — no `//`, no JSDoc, no `<!-- -->`. Exceptions: `tests/**`/`e2e/**` comments, and composables/stores' fixed `// #region`/`// #endregion` structural markers (decision 052). Anything else worth explaining goes in `.claude/docs/standards/` or `.claude/docs/catalog/` instead (decision 041). | Human review; consider `tests/arch/no-code-comments.spec.ts` (backlog)                                                                                                                       |
| 15  | **Zero lint/typecheck suppressions.** No `eslint-disable*`, `@ts-expect-error` or `@ts-ignore` anywhere. Every ESLint/TS complaint gets a real code fix; if truly unfixable, the rule's default severity is a warning (not silenced) and the reasoning is documented in a decision, not in a code comment (decision 041).                                                                                    | `pnpm gate`; consider `tests/arch/no-lint-suppressions.spec.ts` (backlog)                                                                                                                    |
| 16  | **UI/UX pattern consistency (unicity).** A visual/structural treatment introduced in one place (icon next to a heading, timeline mechanism, elevation, control height) is checked against every other place that plays the same role before shipping; a difference is a documented decision, never an accident.                                                                                              | Human review; `.claude/templates/review-checklist.md`                                                                                                                                        |
| 17  | **Verify via tests/gates, not manual browsing, unless asked.** Default to `pnpm gate`/`gate:push` (unit/arch/e2e) to confirm a change works. Never open a local dev server / Browser pane to manually click through without asking first and getting explicit, per-instance acceptance.                                                                                                                      | Human review                                                                                                                                                                                 |
| 18  | **Ask before switching branch/story mid-task.** A new request while mid-task never triggers a silent branch switch or new implementation. Ask: same branch, or queue as a new story for after? Default while unanswered: write the story, touch nothing else.                                                                                                                                                | Human review                                                                                                                                                                                 |
