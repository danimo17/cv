# Standard · i18n

- Files `i18n/locales/{en,ca,es}.json`, **same structure** (parity test). `en` is the source; `ca`/`es` are
  translated in the same change.
- Keys `<area>.<entity>.<field>`: `nav.home`, `hero.cta.contact`, `experience.items.pdpaola-vue.title`,
  `experience.items.pdpaola-vue.bullets[]` (array → `tm()` + `rt()`), `meme.results.empty`.
- JSON holds text only. Dates, URLs, company names, technical tags → `app/data/cv/*.ts`.
- Message arrays (`bullets[]`, `steps[]`) are read with `useMessageList(key)`, never `tm`/`rt` by hand.
- Interpolation `{name}`; plurals with `|`. No HTML inside keys.
- Text via `t()`; `alt`, `aria-label`, `placeholder`, `title` also via `t()`.
- Routes: `<CustomLink to="/meme">` (renders `NuxtLinkLocale`; never `<NuxtLink>`/`<a>` by hand). Language
  switch: `useSwitchLocalePath()` + `<CustomLink :to="…" :localize="false">`.
- `useLocaleHead()` in `app.vue` for `lang`, `dir` and alternates. `useSeoMeta` per page with `meta.*` keys.
- Adding a language: entry in `nuxt.config.ts` `i18n.locales`, full JSON, PDF `public/cv/cv-<code>.pdf`,
  block in `docs/catalog/i18n.md`.
