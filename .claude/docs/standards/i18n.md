# Standard · i18n

- Fitxers `i18n/locales/{en,ca,es}.json`, **mateixa estructura** (test de paritat). `en` és la font; `ca`/`es` es
  tradueixen al mateix canvi.
- Claus `<area>.<entity>.<field>`: `nav.home`, `hero.cta.contact`, `experience.items.pdpaola-vue.title`,
  `experience.items.pdpaola-vue.bullets[]` (array → `tm()` + `rt()`), `meme.results.empty`.
- Al JSON només text. Dates, URLs, noms d'empresa, tags tècnics → `app/data/cv/*.ts`.
- Arrays de missatges (`bullets[]`, `steps[]`) es llegeixen amb `useMessageList(key)`, mai amb `tm`/`rt` a mà.
- Interpolació `{name}`; plurals amb `|`. Res de HTML dins de claus.
- Text amb `t()`; `alt`, `aria-label`, `placeholder`, `title` també per `t()`.
- Rutes: `<CustomLink to="/meme">` (renderitza `NuxtLinkLocale`; mai `<NuxtLink>`/`<a>` a mà). Canvi d'idioma:
  `useSwitchLocalePath()` + `<CustomLink :to="…" :localize="false">`.
- `useLocaleHead()` a `app.vue` per `lang`, `dir` i alternates. `useSeoMeta` per pàgina amb claus `meta.*`.
- Afegir un idioma: entrada a `nuxt.config.ts` `i18n.locales`, JSON complet, PDF `public/cv/cv-<code>.pdf`,
  bloc a `docs/catalog/i18n.md`.
