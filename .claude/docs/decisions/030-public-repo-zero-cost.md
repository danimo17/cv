# 030 · Repo públic i cost zero

**Context.** L'usuari confirma que el repo `danimo17/cv` és públic (el codi és el propòsit de la web) i exigeix que totes les eines i serveis siguin gratuïts.
**Decisió.** Repo públic. Restricció vinculant: cap dependència, servei o acció de pagament. Stack actual, tot gratuït: Nuxt, Tailwind, Pinia, pnpm, Vitest, Playwright, gitleaks, Dependabot, GitHub Actions (il·limitat en públic), CodeQL (gratuït en públic), Cloudflare Workers (pla free), API de Giphy. Única despesa: el domini (12,20 $/any, ja pagat). Les claus i secrets mai són consultables: regla 01 + gitleaks.
**Conseqüències.** Si el repo passés a privat, CodeQL deixaria de ser gratuït i s'hauria de retirar del workflow i del ruleset. Qualsevol proposta futura de servei de pagament es pregunta primer (regla 11).
