# Catalog · Styles (tokens, neumorphic shadows, type scale, per-component classes)

Living documentation (rule 07): a new or changed token, class or state → this file in the same change. Describes what
exists **now**: neumorphism / soft UI (decision 025) on top of the project's own primitives (decision 026).

## Tokens (`app/assets/css/tokens.css`, Tailwind v4 `@theme`)

The only file with raw colors. Dark mode: same names, new values under `.dark` (no component needs `dark:`).
The idea behind the neumorphism: everything is the **same color as the background** (`surface`) and volume comes from two
shadows, a light one top-left (`neu-light`) and a dark one bottom-right (`neu-dark`).

| Token                         | Use                                                                           | Light                      | Dark                  |
| ----------------------------- | ----------------------------------------------------------------------------- | -------------------------- | --------------------- |
| `--font-sans` / `--font-mono` | `font-sans` (body), `font-mono`                                               | system-ui… / ui-monospace… | =                     |
| `--radius-sm/md/lg/xl`        | `rounded-sm/md/lg/xl`                                                         | 0.5 / 0.75 / 1 / 1.5 rem   | =                     |
| `--radius-2xl/3xl`            | `rounded-2xl/3xl` (large frames: hero figure, "how it works" card)            | 2 / 2.5 rem                | =                     |
| `--color-surface`             | page background and base surface for all relief (cards, buttons, frames)      | `oklch(94% .008 250)`      | `oklch(23% .015 250)` |
| `--color-surface-alt`         | background of recessed areas (inputs, filled cards, tracks, skeleton, footer) | `oklch(91.5% .01 250)`     | `oklch(20% .015 250)` |
| `--color-border`              | residual lines (timeline)                                                     | `oklch(86% .012 250)`      | `oklch(32% .015 250)` |
| `--color-text`                | main text                                                                     | `oklch(24% .02 250)`       | `oklch(94% .005 250)` |
| `--color-text-muted`          | secondary text                                                                | `oklch(46% .02 250)`       | `oklch(72% .015 250)` |
| `--color-neu-light`           | light shadow (top-left) of the relief                                         | `oklch(100% 0 0)`          | `oklch(29% .018 250)` |
| `--color-neu-dark`            | dark shadow (bottom-right) of the relief                                      | `oklch(82% .02 250)`       | `oklch(15% .015 250)` |
| `--color-<tone>`              | tone color (`primary, secondary, neutral, success, info, warning, danger`)    | see file                   | see file              |
| `--color-<tone>-fg`           | text over the tone's solid background                                         |                            |                       |
| `--color-<tone>-soft`         | tone's soft background (soft badges, alerts, marquee)                         |                            |                       |

Tones (light → dark, L/C/h in oklch): `primary` (mustard) 50%/.14/88 → 78%/.13/88 · `secondary` (neutral dark gray)
30%/.006/90 → 82%/.006/90 ·
`neutral` 50%/.012/260 → 72%/.01/260 · `success` 48%/.16/150 → 78%/.15/150 · `info` 48%/.14/230 → 78%/.12/230 ·
`warning` 50%/.15/75 → 82%/.15/80 · `danger` 52%/.21/25 → 74%/.18/25. The `-soft` variants sit at L 91-92% (light) / 28-32%
(dark), slightly darker/lighter than `surface` so they're distinguishable without a border.

Every tone has all three tokens (`-`, `-fg`, `-soft`) in light and dark: adding a tone = 6 values + entry in `TONES`
(`app/types/ui.ts`) + modifiers on the primitives that consume it.

### Shadow tokens (`--shadow-*` → `shadow-*` utilities, usable inside `@apply`)

The values reference `var(--color-neu-dark)` / `var(--color-neu-light)`: that's why **`.dark` only redefines the
two colors** and every shadow is recalculated automatically at runtime.

| Token                   | Utility               | Value                                                       | Relief                         |
| ----------------------- | --------------------- | ----------------------------------------------------------- | ------------------------------ |
| `--shadow-neu`          | `shadow-neu`          | `6px 6px 12px neu-dark, -6px -6px 12px neu-light`           | normal relief (raised)         |
| `--shadow-neu-sm`       | `shadow-neu-sm`       | `3px 3px 6px neu-dark, -3px -3px 6px neu-light`             | short relief (hover, badges)   |
| `--shadow-neu-lg`       | `shadow-neu-lg`       | `12px 12px 24px neu-dark, -12px -12px 24px neu-light`       | large relief (elevated, hero)  |
| `--shadow-neu-inset`    | `shadow-neu-inset`    | `inset 4px 4px 8px neu-dark, inset -4px -4px 8px neu-light` | recessed (inputs, pressed)     |
| `--shadow-neu-inset-sm` | `shadow-neu-inset-sm` | `inset 2px 2px 4px neu-dark, inset -2px -2px 4px neu-light` | light recess (tracks, stripes) |
| `--shadow-neu-none`     | `shadow-neu-none`     | `0 0 #0000`                                                 | flat (ghost, links)            |

| Relief      | Utility                          | States that use it                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| ----------- | -------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Raised**  | `shadow-neu` / `-sm` / `-lg`     | button at rest (`neu`), button/nav/icon hover (`neu-sm`), outline card (`neu-sm`) and elevated (`neu-lg`), header (`neu-sm`), hero figure (`neu-lg`), preview image (`neu`), badges (`neu-sm`), alerts (`neu`), timeline dot (`neu-sm`), theme toggle (`neu`), active header nav link (`neu-sm`, `.app-header__link--active`, decision 044 — overrides `CustomLink`'s default inset active state via `activeClass`), meme card (`neu`, hover `neu-inset`), checked radio/checkbox (`neu-sm`), skip link (`neu`) |
| **Pressed** | `shadow-neu-inset`               | button `:active` and `--loading`, theme toggle `:active`, meme card `:active` and `--selected` (+ `ring-2 ring-primary`)                                                                                                                                                                                                                                                                                                                                                                                        |
| **Inset**   | `shadow-neu-inset` / `-inset-sm` | `custom-input__control` (`inset`; focus `+ ring-2 ring-primary/40`; danger `ring-1 ring-danger`), unchecked radio/checkbox (`inset-sm`), filled card (`inset`), skeleton (`inset-sm`), marquee and banner (`inset-sm`), `CustomLink`'s default active state (`inset-sm`, overridden by `AppHeader`, see Raised row), footer (`inset-sm`)                                                                                                                                                                        |
| **Flat**    | `shadow-neu-none` / no shadow    | ghost button at rest, inline/subtle links, sections and pages (the relief is provided by the primitives they contain)                                                                                                                                                                                                                                                                                                                                                                                           |

Cross-cutting rules: `transition-shadow` on everything that changes relief; `prefers-reduced-motion: reduce` cuts
every transition (`base.css`) and the skeleton/marquee animation; state is never conveyed by shadow alone (pressed/selected
also carry a color or ring; focus always carries `outline-primary`).

| `text-muted` / `surface`     | **5.97:1**  | **6.81:1**  |
| `text-muted` / `surface-alt` | **5.53:1**  | **7.30:1**  |
| `primary` / `surface`        | 5.04:1      | 8.39:1      |
| `primary-fg` / `primary`     | 5.83:1      | 9.01:1      |
| `success` / `surface`        | 4.97:1      | 8.93:1      |
| `info` / `surface`           | 5.05:1      | 8.64:1      |

## Base (`base.css`)

`html` `scroll-smooth motion-reduce:scroll-auto` + `color-scheme`; `body` `bg-surface font-sans text-text antialiased`;
`:focus-visible` `outline-2 outline-offset-2 outline-primary`; `prefers-reduced-motion` → global `transition-none`.
App layout: `.app-shell` (flex col, `min-h-dvh`), `.app-shell__main` (`flex-1`), `.skip-link` (sr-only until
focused; on focus `rounded-lg bg-primary shadow-neu`).

## Pages (`pages.css`)

`.page` (`max-w-5xl` container with padding), `.home-page`, `.meme-page` (+ `__header`, `__kicker`, `__intro`,
`__how` (`rounded-2xl`, on top of CustomCard filled), `__how-title`, `__steps`). Layout/spacing only; text is `CustomText`
and the relief is provided by the primitives.

## Layout utilities allowed in templates

None: templates only use classes from the component's own block (`vue/no-restricted-class` blocks `bg-/text-/p-/m-/gap-/…`).
All `@apply` lives in the component's CSS.

## How to customize

1. **Change the surface color** (light or dark): `tokens.css`, `--color-surface` and `--color-surface-alt`. Also move
   `--color-neu-light` / `--color-neu-dark` (roughly 6-12 points of L above and below `surface`) and
   recalculate the `text` / `text-muted` contrast (table above; ≥ 4.5:1).
2. **Change the relief intensity**: only `--shadow-neu*` in `tokens.css` (distance and blur) or the
   L separation between `neu-light` and `neu-dark`. Components don't touch shadow values directly: they use `shadow-neu*`.
3. **Change the border radii**: `--radius-*` in `tokens.css`; every `rounded-*` derives from it.
4. **Add a tone**: 6 values (`-`, `-fg`, `-soft` × light/dark) in `tokens.css`, an entry in `TONES`
   (`app/types/ui.ts`) and `--<tone>` modifiers in `custom-button`, `custom-badge`, `custom-alert`, `custom-link`, `custom-marquee`,
   `custom-text`. Check that `<tone>` over `surface` and `-fg` over `<tone>` both give ≥ 4.5:1.
5. **Change the typography**: `custom-text.css` (variants) or `tokens.css` (`--font-*`). No other file.
6. **Change a primitive's appearance** (button, input, link, image, badge, alert, card): its own `<name>.css`.
   Consumers don't change.
7. **New state/variant of a primitive**: prop + `.<name>--<value>` modifier (pick the relief from the recipe
   table) + row in `catalog/components.md` + row here.
8. **New section/page**: layout only (grid, gaps, margins) in its own `<kebab>.css`; text with `CustomText`, links
   with `CustomLink`, images with `CustomImage`; relief is provided by `CustomCard` or the corresponding primitive.
